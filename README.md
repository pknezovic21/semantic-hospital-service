# semantic-hospital-service

Java 21 and Maven are required to run the service.

```bash
git clone https://github.com/pknezovic21/semantic-hospital-service.git
cd semantic-hospital-service
mvn spring-boot:run
```

After starting, service is available at:
- http://localhost:8080
- Fuseki SPARQL endpoint: http://localhost:3030/hospital/query
